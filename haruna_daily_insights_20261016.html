콘텐츠 아이디어 제안

  1. [즉시 · 오늘 저녁~17일] 「밖에서 돌아온 저녁, 씻고 바르는 순서」 — 오늘 PM2.5 모델값이 78이다. 귀가 → 샤워 → 물기 남았을 때 바디크림 순서 컷이다. 「미세먼지를 막는다 · 보호한다」는 쓰지 않는다. 수치는 에어코리아 관측치로 다시 확인한 뒤 쓴다.
  2. [17일 토 · 낮 24℃] 「바르고 1분, 옷 입기 전」 — 바디크림 #3 장면이다. 바른 뒤 바로 옷을 입는 아침 컷이다. 실키 머쉬룸 제형 서술이 지식창고/하루나 에 확인일자와 함께 있는지 먼저 본다. 없으면 장면만 쓰고 제형 문장은 뺀다.
  3. [21~23일 준비 · 20일 재확인] 「5℃대 아침이 사흘」 — 21~23일 최저 6.6 · 5.5 · 5.1℃, 최저습도 35~36%다. 「정강이가 당기는 첫 주」 장면이다. 10-15 의 「첫 4℃ 아침」 문구는 폐기한다. 20일 예보를 보고 숫자를 확정한다.
  4. [향] 「가까이 왔을 때만」 — 향 축 8회차. 실키 머쉬룸 향을 브랜딩 안내서 기준 한 줄로 소개한다. 「향수 대신」 · 「살냄새」는 남의 문형이라 쓰지 않는다.
  5. [톤 원칙 · 내부] 「숫자 대신 장면」 — 토너 #1 이 근거다. 하루나 콘텐츠는 효능 수치를 걸지 않는다. 날씨 수치와 사용 장면만 쓴다. 게시 전 카피-성분근거-대조 를 거친다.

승격 후보

  1. 🔴 하루나 블로그 후기 — 「착색크림 겸 미백크림」 잔존 (8회차 태깅). 네이버 상위가 6회차 연속 고정이라 매일 같은 자리에 노출된다. 게시물 수정 요청은 외부 발송이라 팀장 직접 항목이다. 결재함 상정 여부를 결정해야 한다.
  2. 수집 경로 — 인스타 · 레딧 · 올리브영 Aside 경로 고정. 인스타는 #태그 URL 이 Aside 에서도 오류 페이지였다. 키워드 검색 URL(explore/search/keyword/?q=<태그>, # 없이)은 5/5 열렸다. 레딧은 Aside 탭(old.reddit)이 로그인월이고 Aside fetch() RSS 는 열린다. 올리브영은 직접 크롤이 6/6 403 으로 넓어졌다. crawl_daily.py 의 이 셋을 Aside 경로로 옮길 후보다. Aside REPL 에는 fs.writeFileSync 가 없다. 그래서 표준출력으로 받아 raw/ 에 옮기는 단계가 필요하다. 수집도구-고르기 업무법 대상이다.
  3. 예보 고정 문구 — 게시 직전 재확인 규칙. 10-15 회차의 「16일 최저습도 31%」가 하루 만에 63% 로 바뀌었다. 「22일 4.5℃」도 5.5℃ 로 바뀌었다. 날짜와 수치를 박은 콘텐츠는 게시 전날 예보로 다시 확인해야 한다. 데이터인사이트 회차 기억 후보다.
  4. 검색 표본 고정 — 네이버 신규 0/36(6회차) · 올영 바디 top10 이틀 동일 · 스레드 3개 검색어 캡션 1건. 검색어 회전이나 최신순 수집으로 바꿀 후보다.
