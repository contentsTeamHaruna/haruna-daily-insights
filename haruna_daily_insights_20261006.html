콘텐츠 아이디어 제안

  1. [오늘 날씨 즉시] 「아침 10℃, 낮 22℃ — 바르고 바로 니트 입기」 — 실키 머쉬룸 바디크림을 바른 직후 옷을 입는 장면만 보여준다. 사용감만 말하고 효능 문장은 쓰지 않는다.
  2. [교체 시점 질문] 스레드 참여형 — 「봄여름엔 로션, 가을겨울엔 크림. 언제 갈아타세요?」 답을 모아 다음 글 소재로 쓴다.
  3. [원료 언어] 「흰목이버섯은 식재료다」 — 원료를 음식 출처로 보여준다. 「미백」 · 「톤」 언어를 쓰지 않는다. 블로그 문안 정정(승격 후보 1번)과 같은 방향이다.
  4. [레이어링 순서] 「워시 → 물기 → 크림, 옷 입기까지 3분」 — 순서와 시간만 보여준다. 향 지속 시간 수치는 쓰지 않는다.
