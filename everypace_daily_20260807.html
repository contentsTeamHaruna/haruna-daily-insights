🛠 상정 필요 (팀장 승인 사항)
1. ★source_week.py resolve() 링크 절단 수리 — 4일 연속 소재 손실. RSS가 넘긴 URL에서 쿼리 파라미터 값이 잘려 나간다(?idxno · ?key · ?mid · ?no). 오늘만 웰니스 22건 / 트렌드 15건이 절단 상태였고, 그중 「말랑이·왁뿌볼 대구 전통시장」(영남일보) 1건을 폐기했다. base64 디코딩 후 파라미터 재조립 로직 수정 필요. 코드 커밋은 팀장 직접 항목이므로 상정만 올린다.
2. ★리포트 HTML 5일 백필 — 8/1~8/4 + 8/6. outputs/ 최신 everypace HTML이 everypace_daily_20260805.html이고 index 최상단도 08-05다. 마크다운 보고서는 전부 있으므로 HTML 5개 생성 + index 5행 추가가 필요하다. 진행 여부 지시 요청.
3. GitHub 업로드 승인. 오늘 8/7분 HTML과 index 갱신본은 로컬까지 만들어 뒀다. GitHub push는 가드레일상 팀장 직접 항목이라 업로드하지 않았다. 승인 시 즉시 반영한다.
4. ★웰니스 소싱처 확장 — 3일 연속 채택 1건 이하. 8/5 1건 · 8/6 1건 · 8/7 1건. 현재 쿼리(번아웃 회복·수면 웰니스 트렌드·자기돌봄 마음챙김·쉼 휴식 트렌드·웰니스 라이프스타일)가 브랜드 PR을 정확히 끌어오는 형태다. 오늘 유일 채택도 RSS 상위가 아니라 매거진(여성동아) 쪽이었다. 여성지·노동/사회 매체·기획기사 중심 소스 추가를 제안한다.
5. RSS 창 축소 검토. --days 3인데도 어제 채택분이 재공급됐다(요가매트 건). --days 2 고정 또는 채택 이력 대조 자동화(정규화 제목+게재일 기준)를 제안한다.
