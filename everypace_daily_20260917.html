📮 상정
🔴 1. 트렌드 축 검색어도 교체 대상에 넣을 것 — 오늘 RSS 채택 0건이다. 현행 5개는 전부 ‘SNS 유행’ 어휘라 연예 챌린지·신제품 홍보·도박 SEO 스팸을 끌어온다. 오늘 채택한 「런치 러닝」은 이 5개 중 무엇으로도 안 잡혔다. 웰니스 축 검색어 교체 상정(12회째)에 트렌드 축을 병합해 올린다. 코드 변경 = 승인 항목.
🔴 2. RSS 밖 채널을 하나 붙일 것 — 네이트 「네티즌관심뉴스」. 오늘 유일한 트렌드 소재가 여기서 나왔다. 검색어 기반이 아니라 실제 클릭 순위라서 관문①(실제 인게이지먼트)과 결이 맞고, EUC-KR·?mid 제거만 알면 무료로 긁힌다(everypace-link-recovery-tricks ⟨auto-memory⟩). 섹션 2개(경제·시사)면 충분하다.
🟡 3. resolve() 가 절반짜리 URL을 반환하는 것을 고칠 것. 오늘 4건이 = 직전에서 잘린 문자열을 받았고 겉보기엔 정상 URL이라 그대로 게재할 뻔했다. 최소 조치는 반환 직전 ?+파라미터명으로 끝나면 None 을 반환하는 한 줄이다. 구글뉴스 ID 가 암호화형으로 바뀌는 중이라 resolve 성공률 자체는 회복 불가로 본다 — §2(매체 직접 수집)가 근본 대응이다.
