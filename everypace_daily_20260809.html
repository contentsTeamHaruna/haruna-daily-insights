런갤 크롤: 무료 HTTP 크롤(urllib + 정규식 파싱)로 1~12p 병렬 수집 → 8/8분 681건 확정(이진탐색으로 경계 확인: 12p가 8/7로 넘어가 구간 완전 포함). 댓글은 dcinside 코멘트 API로 원문 대조. 코드 커밋 = 팀장 직접 항목이라 스크립트는 세션 스크래치패드에만 두었다.

★상정 1 — source_week.py 링크 절단, 6일 연속 미해결. RSS 파싱에서 ?idxno·?No·?key·?mode 등 쿼리 파라미터 값이 잘려 오늘도 웰니스 19건 중 10건 / 트렌드 7건 중 2건이 링크 확정 불가 상태였다. 오늘 채택분은 절단되지 않은 링크라 손실이 없었지만, 어제는 이 때문에 영남일보 기사 1건을 폐기했고 오늘도 오아시스뉴스 콰이어트케이션 1건을 폐기했다. 원인은 RSS <link> 추출 정규식이 &·= 이후를 못 살리는 것으로 보인다. ⛔ 코드 수정 = 팀장 직접이라 상정만 한다.

★상정 2 — 리포트 HTML 결손 2일치(8/5 · 8/7), 이틀째 미회신. everypace_daily_20260805.html·everypace_daily_20260807.html이 없고 index 배열에도 08-05·08-07 두 줄이 빠져 있다(현재 최상단 08-08 → 08-06 → 08-04). 마크다운 보고서는 둘 다 정상 존재하므로 HTML 2개 + index 2행이면 끝난다. 어제 요청분이 회신되지 않아 오늘도 진행하지 않았다 — 진행 여부 지시 요망.

상정 3 — GitHub 업로드 승인: 오늘 8/9분 HTML과 index 갱신본을 로컬까지 만들어 뒀다. GitHub push는 가드레일상 팀장 직접 항목이라 실행하지 않았다. 승인 시 즉시 반영한다.

★상정 4 — 웰니스 소싱처 확장(6일 중 5일이 채택 0~1건). 오늘 19건 중 18건이 보도자료·행사 고지였고, 제약 전문지 5곳이 같은 기사를 싣는 구조가 어제와 똑같이 반복됐다. 현재 쿼리(번아웃 회복·수면 웰니스 트렌드·자기돌봄 마음챙김·쉼 휴식 트렌드·웰니스 라이프스타일)에서 「웰니스」가 국내 기사에서 사실상 업계 용어로 쓰여 검색어가 정확히 제약·호텔·한의원 PR을 끌어온다. 제안: ① 쿼리에서 웰니스를 빼고 생활 언어(잠 못 자는·쉬는 법·퇴근 후·혼자 있는 시간)로 교체, ② 자체 취재 매체 화이트리스트 도입. ⛔ 쿼리 변경 = 코드 수정이므로 상정만 한다.

★상정 5 — 채택 이력 자동 대조. 이코리아 기사가 --days 2에서도 사흘째 재공급됐다. 오늘은 수동 대조로 걸렀으나, 채택·배제 이력을 _gnews_seen.json에 누적하고 정규화 제목+게재일로 자동 대조하는 것이 근본 해법이다(everypace-dedup-key-not-url). 상정 1번과 함께 처리 요청.
