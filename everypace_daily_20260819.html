📌 팀장 상정 (확인 필요)
1. 4일 결손(8/15~8/18) 원인 확인 — 🆕 최우선. 직전 보고서가 8/14다. 스케줄 실행이 돌지 않은 것인지, 돌았는데 산출이 없었는지 확인이 필요하다. 뉴스 축은 3일 창이라 소급 복구가 사실상 불가능하다.
2. 웰니스 검색어 교체 — 재상정. 정본 source_week.py의 웰니스 5개 검색어("번아웃 회복"·"수면 웰니스 트렌드"·"자기돌봄 마음챙김"·"쉼 휴식 트렌드"·"웰니스 라이프스타일")는 홍보 문구와 그대로 겹쳐 38건 중 31건이 보도자료로 돌아온다. 8/14에 「번아웃/회복 휴식/수면의 질/마음챙김/자기돌봄/운동 습관/정신건강/스트레스 관리」로 바꿔 돌렸을 때 채택 1→4건. 스크립트 수정은 승인 항목이라 상정만 한다.
3. 채택 이력 자동 대조 — 계속 미해결. 오늘도 촉감 소비 재탕을 사람이 손으로 걸렀다. 정규화 제목+게재일 이력 대조를 source_week.py에 넣는 건이 그대로 남아 있다.
4. GitHub 업로드 승인 — 대기. 오늘분 리포트 HTML과 index 갱신은 로컬까지 만들어 뒀다. GitHub push는 가드레일상 팀장 직접 항목이라 업로드하지 않았다. 사이트는 여전히 7/16에서 멈춰 있다.
